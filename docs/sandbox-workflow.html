01 / NETWORK & EXECUTION

T3 Connect finds projects. Tailscale provides private transport.

The controller registers environments. Devices sign in to the same T3 account and choose one. T3 Connect uses a managed HTTPS tunnel; Tailscale can provide a separate private route to the controller and project endpoints.

View

Swipe horizontally to see the full diagram.

T3 Connect is the automatic environment-list path. A controller registration makes the environment available to devices signed in to the same account. Your personal desktop does not need to remain on.

Account access and execution are separate

The trusted controller links environments and runs their tunnel connectors. Each sandbox receives only its environment-specific relay configuration. T3 sessions, terminals, Git commands and agent processes execute in that project's sandbox.

Tailscale does not add entries to T3

Tailscale solves reachability and private HTTPS. Direct T3 pairing still authorizes a device for an environment. T3 Connect provides the account catalog; it normally does not require Tailscale on the client.

02 / ADD A PROJECT

One controller action prepares a usable T3 environment

Repository access must succeed before the controller reports the environment as ready.

There is no per-project account login. A failure leaves the project pending or blocked with a retryable status; it does not advertise successful access.

04 / OPTIONAL REPOSITORY IMPORT

Your Forgejo copy can become the sandbox's origin

This is a planned repository feature, separate from the T3 Connect qualification. Existing Forgejo and GitHub repositories use the controller's current access flow.

GitLab authorization, import retries, naming conflicts and safe cleanup must pass their own checks before this option is enabled.

05 / PAUSE, RESUME & REMOVE

Remote registration is part of the project lifecycle

Persist registration intent before contacting T3 Connect. If provisioning or removal is interrupted, retry from the durable ledger. A removal is incomplete while external revocation or owned storage cleanup is unverified.
